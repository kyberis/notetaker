# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be patient, don't be a jerk. Disagreements about code are
welcome; ad-hominem attacks are not.

## Reporting

To report a violation, email **conduct@trefolio.com**. All reports stay
confidential. The maintainer will respond within seven days.
